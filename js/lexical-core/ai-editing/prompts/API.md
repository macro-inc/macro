# `editor` API

All edits go through the `editor` object. `id` is a node id from the XML. Methods
that create a node **return a handle** you can pass to later calls. Pass plain
text only. `scope` (optional) is `{ all: true }` (default for matches),
`{ nth: N }` (1-based), or omitted (first match).

Each section ends with one worked example: the starting doc, the code, and the
real XML it produces. Examples are generated by `scripts/api-examples.ts`.

## Inline formatting (block id + substring)
- `bold(id, match, scope?)` · `italic` · `underline` · `strike` · `inlineCode`
- `unbold(id, match, scope?)` · `unitalic` · `ununderline` · `unstrike` · `uninlineCode`
- `format(id, match, format, on?, scope?)` — `format` ∈ bold|italic|underline|strike|code
- `clearFormat(id, match?, scope?)` — strip formats on a match; omit `match` for the whole block
- `clearAllFormat(id)`
- `highlight(id, match, scope?)` · `unhighlight(id, match, scope?)`
- `link(id, match, url, scope?)` · `unlink(id, match, scope?)`

```ts
// doc: the quick brown fox
editor.bold('b1', 'quick');
editor.italic('b1', 'brown');
editor.highlight('b1', 'the');
editor.link('b1', 'fox', 'https://x');
```
```xml
<doc>
  <p id="b1">
    <mark id="b2" direction="null" format="" indent="0" version="1" ids="[]">
      <t id="t1">the</t>
    </mark>
    <t id="t2"> </t>
    <t id="t3" bold="true">quick</t>
    <t id="t4"> </t>
    <t id="t5" italic="true">brown</t>
    <t id="t6"> </t>
    <a id="b3" href="https://x">
      <t id="t7">fox</t>
    </a>
  </p>
</doc>
```

## Inline formatting (text-node id directly)
- `boldNode(textId)` · `italicNode` · `underlineNode` · `strikeNode` · `codeNode`
- `formatNode(textId, format, on?)` · `clearNodeFormat(textId)`

```ts
// doc: Hello world  (t1 is the text node inside b1)
editor.boldNode('t1');
editor.underlineNode('t1');
```
```xml
<doc>
  <p id="b1">
    <t id="t1" bold="true" underline="true">Hello world</t>
  </p>
</doc>
```

## Text content
- `setText(id, text)` — replace a block's content with plain text
- `replace(id, find, to, scope?)` — literal find/replace
- `appendText(id, text)` · `prependText(id, text)`

```ts
// doc: first / second / third  (three paragraphs)
editor.setText('b1', 'replaced');
editor.appendText('b2', '!!!');
editor.prependText('b3', '> ');
editor.replace('b3', 'third', 'THIRD');
```
```xml
<doc>
  <p id="b1">
    <t id="t1">replaced</t>
  </p>
  <p id="b2">
    <t id="t2">second!!!</t>
  </p>
  <p id="b3">
    <t id="t3">&gt; THIRD</t>
  </p>
</doc>
```

## Block type
- `makeParagraph(id)` · `makeHeading(id, level)` · `makeQuote(id)` · `makeCodeBlock(id, language?)`

```ts
// doc: Title / A quote / code here  (three paragraphs)
editor.makeHeading('b1', 2);
editor.makeQuote('b2');
editor.makeCodeBlock('b3', 'ts');
```
```xml
<doc>
  <h2 id="b1">
    <t id="t1">Title</t>
  </h2>
  <blockquote id="b2">
    <t id="t2">A quote</t>
  </blockquote>
  <code id="b3" direction="null" format="" indent="0" version="1" language="null">
    <t id="t3">code here</t>
  </code>
</doc>
```

## Lists
- `bulletList(idOrIds)` · `numberedList(idOrIds)` · `checklist(idOrIds)` · `setListType(id, kind)`
- `check(id)` · `uncheck(id)` · `setChecked(id, bool)`
- `indent(id, by?)` · `outdent(id, by?)` · `setIndent(id, level)`
- `sortList(id, order?)`

```ts
// doc: task a / task b  (two paragraphs)
editor.checklist(['b1', 'b2']);
editor.check('b1');
editor.indent('b2');
```
```xml
<doc>
  <ul id="b3" listType="check">
    <li id="b4">
      <t id="t1">task a</t>
    </li>
    <li id="b5" value="2">
      <t id="t2">task b</t>
    </li>
  </ul>
</doc>
```

## Structure (creators return a handle)
- `insertParagraphAfter(id, text?)` · `insertParagraphBefore(id, text?)`
- `insertHeadingAfter(id, level, text?)` · `insertHeadingBefore(id, level, text?)`
- `insertQuoteAfter(id, text?)` · `insertCodeBlockAfter(id, language?, text?)`
- `insertBlockAfter(id, spec)` · `insertBlockBefore(id, spec)` — `spec` is a node spec object
- `appendParagraph(text?)` · `prependParagraph(text?)` · `appendBlock(spec)` · `prependBlock(spec)`
- `move(id, position)` — position is `{ after: id }`, `{ before: id }`, `{ appendToRoot: true }`, or `{ prependToRoot: true }`
- `remove(id)` · `removeMany(ids)` · `merge(ids, separator?)` · `split(id, atText)`

```ts
// doc: Intro / Body  (two paragraphs)
editor.insertHeadingBefore('b1', 1, 'Title');
const c = editor.insertParagraphAfter('b2', 'Conclusion');
editor.appendText(c, '!');
editor.appendParagraph('Footer');
```
```xml
<doc>
  <h1 id="b3">
    <t id="t1">Title</t>
  </h1>
  <p id="b1">
    <t id="t2">Intro</t>
  </p>
  <p id="b2">
    <t id="t3">Body</t>
  </p>
  <p id="b4">
    <t id="t4">Conclusion!</t>
  </p>
  <p id="b5">
    <t id="t5">Footer</t>
  </p>
</doc>
```

## Tables (creators return a handle)
- `insertTableAfter(id, rows)` · `insertTableBefore(id, rows)` · `appendTable(rows)` — `rows` is `string[][]`, row 0 is the header
- `setCell(tableId, row, col, text)`
- `addRow(tableId, at?)` · `addColumn(tableId, at?)` · `removeRow(tableId, row)` · `removeColumn(tableId, col)`

```ts
// doc: Tasks  (one paragraph)
const t = editor.appendTable([['Item', 'Done']]);
editor.addRow(t);
editor.setCell(t, 1, 1, 'yes');
```
```xml
<doc>
  <p id="b1">
    <t id="t1">Tasks</t>
  </p>
  <table id="b2">
    <tr id="b3">
      <td id="b4" headerState="1">
        <p id="b5">
          <t id="t2">Item</t>
        </p>
      </td>
      <td id="b6" headerState="1">
        <p id="b7">
          <t id="t3">Done</t>
        </p>
      </td>
    </tr>
    <tr id="b8">
      <td id="b9">
        <p id="b10"/>
      </td>
      <td id="b11">
        <p id="b12">
          <t id="t4">yes</t>
        </p>
      </td>
    </tr>
  </table>
</doc>
```

## Media / math / inline objects (creators return a handle)
- `insertDivider(afterId)`
- `insertImage(afterId, { srcType, url, alt?, width?, height? })`
- `insertVideo(afterId, { srcType, url, controls?, width?, height? })`
- `insertEquation(afterId, tex)` · `insertInlineEquation(blockId, at, tex)`
- `insertLineBreak(blockId, at)`
- `insertDate(blockId, at, isoDate, displayFormat?)`

```ts
// doc: Above / Below  (two paragraphs); inserts stack after b1
editor.insertDivider('b1');
editor.insertImage('b1', { srcType: 'url', url: 'https://x/cat.png', alt: 'cat' });
editor.insertInlineEquation('b2', 0, 'x^2');
```
```xml
<doc>
  <p id="b1">
    <t id="t1">Above</t>
  </p>
  <image id="b3" version="1" srcType="url" _id="" url="https://x/cat.png" width="0" height="0" scale="1" constrainedWidth="null" constrainedHeight="null" alt="cat"/>
  <hr id="b4"/>
  <p id="b2">
    <equation id="b5" version="1" equation="x^2" inline="true"/>
    <t id="t2">Below</t>
  </p>
</doc>
```

## Node specs (for `insertBlockAfter`, `appendBlock`, …)
`{ block: 'paragraph', text? }` · `{ block: 'heading', level, text? }` ·
`{ block: 'quote', text? }` · `{ block: 'code', language?, text? }` ·
`{ block: 'list', list: 'bullet'|'number'|'check', items: string[] }` ·
`{ block: 'table', rows }` · `{ block: 'divider' }` ·
`{ block: 'image', srcType, url, alt?, width?, height? }` · `{ block: 'video', … }` ·
`{ block: 'equation', tex, inline? }`

```ts
// doc: Doc  (one paragraph)
editor.appendBlock({ block: 'heading', level: 2, text: 'Section' });
editor.appendBlock({ block: 'list', list: 'check', items: ['todo a', 'todo b'] });
editor.appendBlock({ block: 'code', language: 'ts', text: 'const x = 1' });
```
```xml
<doc>
  <p id="b1">
    <t id="t1">Doc</t>
  </p>
  <h2 id="b2">
    <t id="t2">Section</t>
  </h2>
  <ul id="b3" listType="check">
    <li id="b4">
      <t id="t3">todo a</t>
    </li>
    <li id="b5" value="2">
      <t id="t4">todo b</t>
    </li>
  </ul>
  <code id="b6" direction="null" format="" indent="0" version="1" language="null">
    <t id="t5">const x = 1</t>
  </code>
</doc>
```
