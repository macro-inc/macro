# Macro Bots

The standalone Bots app starts at `/` in Character Creator. In the local
fixture preview, choose a preset, change the portrait width, and edit the bot
name. Hire opens a local sign-in screen. Use Go back to restore the same
draft in the current tab. Macro sign-in and hiring require a future local
integration.

Open Fleet at `/fleet` or from the header. Add bot opens Creator. In fixture
mode, each sample bot has a Brain with Overview, Activity, Email, and Access
tabs. Passwords and Billing are Tower routes alongside Fleet. Billing reserves
navigation for a later integration.

## Team Passwords

Open `/passwords` from the header in fixture mode. Pick a folder and an item
to read its details. Add item opens the six item types, and Edit opens the
selected item in the same surface. The default fixture is a team admin.
Use `?actor=creator` to see a member with one restricted item they can edit,
or `?actor=member` to see shared items with read-only access. Only admins can
add items. Use `?case=empty` and save the first item to exercise setup.
`?case=incompatible` and `?case=recovery` exercise the two setup failure states.

Use fictional input. Secrets remain masked and only their presence is kept
after saving. Changes reset when the route is reopened or reloaded. Optional
card guidance is local fixture text. The vault shows read-only agent access
counts. Management belongs to the separate Brain Access integration.
