# Macro Bots

The standalone Bots app starts at `/` in Character Creator. In the local
fixture preview, choose a preset, change the portrait width, and edit the bot
name. Hire opens a local sign-in screen. Use Go back to restore the same
draft in the current tab. Macro sign-in and hiring require a future local
integration.

Open Fleet at `/fleet` or from the header. Add bot opens Creator. In fixture
mode, each sample bot has a Brain with Overview, Activity, Email, and Access
tabs. In Overview, use Schedule to expand the sample schedule and read the
dated Daily journal. Activity shows the newest observations first. Only rows
with a fixture detail offer Open, and Back to Activity returns to the same
bot. Kestrel's fixture displays setup and empty work. The accepted Hire fixture
retains the exact selected agent and shows Setting up in the current tab.
After reload, that synthetic receipt is unavailable. Unknown teams, bots and
inaccessible details display Unavailable. Use Tab to reach a tab and
Enter to open it.

In the local fixture preview, open Finch's Hub from Fleet and select Email for
the read-only inbox. The header labels its synthetic address as a sample
mailbox. Filter by sender or subject. Use Up and Down to move between inbox
rows, then Enter to open the focused thread. On narrow screens, the inbox
scrolls above the thread. A bot that is Setting up shows mailbox setup in
progress. Other bots without a mailbox show Mailbox unavailable.

Open Access in Sable’s Hub to review missing Login and Card requests inline.
Choose Link existing to see eligible items from the same team. The explicit
team admin fixture also offers Add & share new and Decline. Matching or adding
a card leaves it Awaiting human. Card number and security code stay masked,
and the fixture makes no charge. Quill has one missing-item request. Kestrel
shows account setup and an empty Passwords panel. Account grants and revokes
are unavailable in this flow. Request decisions live in the current Access
view and reset when it closes.

Computer remains unavailable. Passwords and Billing remain Tower routes
alongside Fleet. Brain sample data is present only in the local fixture build.
