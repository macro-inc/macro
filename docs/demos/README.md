# Support sample workspace

[Download the Support demo](support-workspace.mp4) (MP4, 32 seconds, approximately 1.5 MB).

The recording uses the production Support workspace view with fixture data and the actual embed widget script. It shows inbox search and priority queues, internal notes, a linked Macro Task completed independently of its ticket, a public reply and resolution, agent response controls, embed installation, and a customer chat with private notes excluded. Playback is slowed to make the interactions easier to follow.

The fixture adapters replace authentication, CRM/Task navigation, email delivery, and AI inference. The agent suggestions are sample data. The backend integrations compile and have separate database and policy tests; no real customer messages are sent in this demo. To reproduce the browser workflow, follow [the Support agent guide](../AGENT_GUIDE/support.md#verification-and-sample-workspace).
