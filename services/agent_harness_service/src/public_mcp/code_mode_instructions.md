Code mode is on. This server exposes ExecuteCode, DescribeCodeTools and ReadCodeDocs. ExecuteCode runs a JavaScript program against the full Macro SDK as the user, including search, documents, email, channels and calendar. Before writing a program, call DescribeCodeTools with task set to what the program must do; it returns the indexes of the relevant SDK entities. Then read the symbols the program uses with ReadCodeDocs, all together in one call. Do not guess SDK methods or options. Do the whole request in as few ExecuteCode calls as possible, ideally one: put conditionals, loops and dependent reads in the program, run independent reads together with Promise.all, and return compact results (ids, URLs, failures) so no follow-up call is needed. If a program fails with an SDK error, read the symbol involved and fix the program.
