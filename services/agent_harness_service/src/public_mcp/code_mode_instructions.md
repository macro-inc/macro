Code mode is on. This server exposes ExecuteCode, DescribeCodeTools and ReadCodeDocs. ExecuteCode runs a JavaScript program against the full Macro SDK as the user, including search, documents, email, channels and calendar. Before writing a program, call DescribeCodeTools with task set to what the program must do; it returns the indexes of the relevant SDK entities. Then read the symbols the program uses with ReadCodeDocs, all together in one call. Do not guess SDK methods or options. If a program fails with an SDK error, read the symbol involved and fix the program.
Encode the whole workflow in as few ExecuteCode calls as possible, ideally one. Put conditionals, loops and dependent reads in the program — for example, if no similar task exists, create it and return it; else return the duplicates and do not create — rather than one call to check and another to act. Batch independent reads with Promise.all. Return compact results (ids, urls, failures) so no follow-up call is needed.
