# Native document sessions

`NativeEditorSession` and `NativeDocSession` expose the portable core through
UniFFI 0.32.2. Build with `cargo build -p document_session_ffi -j2` for the matching
static library and dynamic library. Swift (`DocumentSession`) and Kotlin
(`com.macro.documentsession`) bindings are committed under `bindings/`.
Regenerate with `bun crates/client/document_session_ffi/scripts/generate-bindings.ts`;
add `--check` to verify exact generated bytes and file names.

Construct with a complete `FfiSessionConfig`, optional storage path, and sampled
monotonic/wall clocks. Call `handle(Start)`, execute returned host effects, and
submit completions as subsequent inputs. Each call admits one native input.
Calls and queries are serialized by a mutex; no socket, storage or other host I/O
runs under that mutex. Outputs own their data and retain effect order. Commit tags, resolved remote
cursors and forced composition-end requests reach the native view unchanged. Native
editors always use `ViewEngine::Native`; routed transport and chatter are rejected.

Query `FfiQuery::ViewDiff` for a full repaint when attaching a new native view;
it preserves live model keys, history and synchronization.

All inputs, structured Diff operations, selection context, queries, storage
metadata and telemetry use typed UniFFI records/enums. Container snapshots, sync
frames and Loro cursors retain their native opaque byte formats. Bebop/postcard
are not used for this boundary. Host-generated peer identities and both clocks
are explicit; clock regression is rejected before entering the core.

No `doc_store_turso` executor exists in this workspace yet. Passing `store_path`
returns `StoreNotConfigured`; use `None` and execute typed storage effects in the
host. This permits durable operation without silently discarding a storage path.
WAL adoption retains the exact loaded expected rows for atomic source validation.
The application field selects the same surface preset, MACRO_SYNC_POLICY, comment
factory, supplied wall clock and continuing per-peer entropy used by WASM. Leave
it absent for portable core/rich nodes. Application command/query catalogs and
plugin-event payloads remain typed native values; host I/O stays outside Rust.
Application Markdown uses internal/external transformers and the supplied
hostname; SavedState returns the download projection with regenerated search text.

`cargo test -p document_session_ffi --features conformance -j2` runs literal native
session scenarios and the unchanged Tier A interpreter through its generated C
entry point. The fixture entry point is development-only and absent from default
builds/bindings. The literal editor test additionally calls the generated session
handle entry point, exercising typed input, structured Diff and output conversion.
The corpus interpreter itself does not route every upstream operation through
`NativeEditorSession::handle`.

On Linux, check iOS simulator and Android targets with `cargo check --target ...`.
iOS cannot link here. With an Android-capable Rust toolchain and `NDK_HOME` set,
run `bun crates/client/document_session_ffi/scripts/build-android.ts
x86_64-linux-android` (or `aarch64-linux-android`). This selects the API 24
compiler/linker and limits Cargo to two jobs. Generated bindings stay in this
crate; Android host integration lives in `apps/web/tauri/native_editor_plugin`.

Query `ShouldInsertText` before native insertion: a true result requires the
model insertion command, including changed typing attributes and token boundaries.
Other native typing uses `FfiInput::TextDeltaFromView(ViewTextDelta)` with UTF-16
start/deletion lengths and only the inserted text. Full `TextFromView` is explicit
resynchronization. Use `ModifyTarget::RequireView` when layout endpoints are
required and unavailable; never silently substitute `NoView`.
Reattach a running editor with `ViewDiff` and its current selection; do not
restart or reseed the session to repaint a view.
Binding generation pins this worktree's target directory and explicitly selects
the compiler's host triple for both library and generator, so inherited
`CARGO_TARGET_DIR` or `CARGO_BUILD_TARGET` overrides cannot select stale artifacts.
