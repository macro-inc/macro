The provided macro is already authenticated; main also receives token and hosts for explicit construction. Never expose the token.
Entity handles are lazy: byId returns a handle, a field accessor may fetch data, search/recent/inbox return async iterators. Await methods and use for await for iterators. Return plain JSON as {data, reviews}; reviews contains references to actual saved review entities, usually []. No sdk.ToolName, runtime documentation helper, TypeScript compilation or package fetching.
A compact entity index is supplied automatically; Jev may expand relevant declarations before the turn. DescribeCodeTools supplies more entity declarations and workflow guides. APIs enforce normal user permissions and metering. Execution has a 30-second deadline; use small parallel batches and early stopping when sufficient. Source and final result are retained in the session journal, not credentials. Direct API calls are not individually captured as old tool receipts.
