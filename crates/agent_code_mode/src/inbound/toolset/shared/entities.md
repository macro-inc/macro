Entity handles are lazy: byId returns a handle, a field accessor may fetch data, search/recent/inbox return async iterators. Await methods and use for await for iterators. No sdk.ToolName proxy, runtime documentation helper, TypeScript compilation or package fetching. APIs enforce normal user permissions and metering. Execution has a 30-second deadline, and calling one SDK operation more than 200 times stops the whole run as a likely loop; use small parallel batches, read each item once, and stop early when you have enough.
