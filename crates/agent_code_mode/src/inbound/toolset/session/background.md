Optional. {title} runs this program as a background job, so the person can keep talking to you while it runs. Use it when the program is expected to take more than about 10 seconds or the person need not wait for its result, such as scanning a whole inbox, reading many documents, or writing many of your own items. The call returns at once with status running and a job; then tell the person in one sentence what you started and that you will report back, and end your turn. The job runs for up to 10 minutes with this turn's account, never asks for approval, and cannot open UI; it may only read and draft reviews or present views in this session; it can't change any existing item (documents, tasks, email, CRM, databases, projects), send email or messages, save routines, call connected apps, use the web or link previews, share, or invite. Run a program that does more in the foreground, without background; sends: true runs it in the foreground too. When it ends, a job.settled event brings you its status and result, and you report it then. Its writes are not retried for you: after a failure, cancellation or interruption, check current state before writing again. Running jobs and recent ones are listed in each prompt's background_jobs. At most 3 jobs run per session. Where background jobs are not allowed (a turn someone other than the session owner prompted, or a system turn), the program runs in the foreground and the receipt says why in ranInForeground.
