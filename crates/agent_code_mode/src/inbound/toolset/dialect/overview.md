ExecuteCode runs a JavaScript tools program: plain JavaScript run as one script, with top-level await and return. Its only way to Macro is an operation call, await tools.<service>.<operation>({path, query, body}): service is a Macro service with - written _ (storage, email, calendar, agent_harness, ...), operation its operationId, and path, query and body its path parameters, query parameters and JSON body, each left out when it has none. A call returns the response's JSON and throws "HTTP <status>: <body>" for an error response. Every operation a program names is checked against your permissions before it runs: never stops it unrun, ask waits for a person. The program's return value is the result's data, or return {data, reviews, images} to show drafts or images. Library and computation work goes in an optional TypeScript module beside the program, read with get and call.
