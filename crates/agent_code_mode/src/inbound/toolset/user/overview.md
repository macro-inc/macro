Use the real Macro SDK, prebundled for Deno. Write a TypeScript ES module exporting async main({macro}: CodeContext); it is type-checked against the SDK before it runs. optionally import {Macro} from "@macro-inc/sdk" or Handlebars from "handlebars". The provided macro is already authenticated as the signed-in user; main also receives token, hosts and webAppUrl for explicit construction. Never expose the token. Return plain JSON as {data}. Nothing is saved between executions.
