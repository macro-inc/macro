Use the real Macro SDK, prebundled for Deno. Write an ES module exporting async main({macro}); optionally import {Macro} from "@macro-inc/sdk", Handlebars from "handlebars" or * as photon from "photon" for local image editing. The provided macro is already authenticated as the signed-in user; main also receives token, hosts and webAppUrl for explicit construction. Never expose the token. Return plain JSON as {data}. Nothing is saved between executions.
