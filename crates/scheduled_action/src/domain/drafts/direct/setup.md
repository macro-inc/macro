- `setup`, a field of the routine only when the request asks for something new that the routine then uses by id (a database it adds rows to, a folder it files into, a channel it posts in): a TypeScript module like a code step's, `export async function main({ macro }: StepContext)`, that creates it once, now, named as the request names it, and returns `{ "<key>": { "type": "<its entity type, such as database or channel>", "id": <its id> } }`. Write `{{setup.<key>}}` wherever the routine uses that id; it is replaced with the id once setup has run. Create nothing else in it, and never do the routine's own work there. Leave `setup` out when nothing needs creating.
