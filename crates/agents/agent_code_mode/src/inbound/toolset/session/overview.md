Use the real Macro SDK, prebundled for Deno. Write an ES module exporting async main({macro,session,execution}); optionally import {Macro} from "@macro-inc/sdk" or Handlebars from "handlebars". The provided macro is already authenticated; main also receives token and hosts for explicit construction. Never expose the token. Return plain JSON as {data, reviews}; reviews contains references to actual saved review entities, usually [].
A compact entity catalog is supplied automatically; Jev may load the indexes of relevant entities before the turn. DescribeCodeTools supplies more entity indexes and workflow guides, and ReadCodeDocs the reference for any symbol an index names. Source and final result are retained in the session journal, not credentials. Direct API calls are not individually captured as old tool receipts.
