## Default Permission

Android notification permission, registration and event bridge.

#### This default permission set includes the following:

- `allow-check-permissions`
- `allow-request-permissions`
- `allow-register`
- `allow-configure`
- `allow-watch`
- `allow-unwatch`
- `allow-acknowledge`
