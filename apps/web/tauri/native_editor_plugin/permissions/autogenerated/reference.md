## Default Permission

Native editor session lifetime, placement and application callbacks.

#### This default permission set includes the following:

- `allow-begin-account`
- `allow-create`
- `allow-mount`
- `allow-layout`
- `allow-focus`
- `allow-permissions`
- `allow-token-result`
- `allow-action`
- `allow-menu-rows`
- `allow-menu-commit`
- `allow-query`
- `allow-lifecycle`
- `allow-unmount`
- `allow-stop`
