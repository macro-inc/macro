## Default Permission

iOS push registration and acknowledged notification navigation.

#### This default permission set includes the following:

- `allow-check-permissions`
- `allow-request-permissions`
- `allow-check-registration-status`
- `allow-register-for-remote-notifications`
- `allow-watch-notifications`
- `allow-unwatch-notifications`
- `allow-get-pending-notification`
- `allow-acknowledge-notification`
- `allow-clear-pending-notification`
- `allow-release-notification-cover`
- `allow-configure-recipient`
