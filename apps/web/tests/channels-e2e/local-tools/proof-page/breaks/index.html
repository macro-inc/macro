Back to the suite result

To show that each test can fail, the product was broken on purpose where the behaviour lives, the app rebuilt, and the suite run against it. These are the 56 patches that broke it, what each run did, and which break each test failed for. They were in the pull request under ledger/breaks/ and ledger/proofs.tsv until 17 November 2026, when they were taken out of the committed suite; this is the copy that was kept. The 11 tests with no row assert behaviour main does not have, so they fail on main unbroken.

Whole table as a file: proofs.tsv. The breaks were made before the last changes to CHN-02, ACC-06, CHN-08, UNR-08 and SCROLL-04 and were not run again after them.
