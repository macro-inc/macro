# Source Magic admission control

This fixture mounts the actual initialized Source MagicChipNode and existing
application component through createLexicalWrapper and DecoratorRenderer. It
imports before the first decorator observation and supplies the same denied
session HTTP scenario to both ordinary and admitted-value cases. It does not
substitute model nodes, renderers or session controllers, and has no native
module/artifact dependency.

The control preserves actual exported JSON and compares literal mounted DOM for
object promptedMessage versus the Source-admitted array plus null channelId.
Separate Chromium, Firefox and WebKit attachments pin both cases. UI input
widening must preserve these bytes; public node data/props stay unchanged.
Session success, native rendering and cached remount behavior remain separate.

The same captures guard the optional Magic host seam: absent host props retain
the real Lexical wrapper path. Native rows and their owned view context are
documented in ../cached-views.md; this fixture claims no native authority.
