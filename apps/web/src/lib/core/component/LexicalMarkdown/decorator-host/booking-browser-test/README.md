# Booking decorator Source boundary

The fixture uses the actual Source wrapper, registered Booking node/component,
selection store, document metadata, trailing paragraph, hover providers and
Normal-priority Enter registration. The factory page exports a real saved model;
the mounted page imports those exact bytes before its first decorator observation.
The nullable case changes only the input label/slug to literal null, then uses
actual Source parse and render. Public node data types remain unchanged.

Seven cases cover saved label, supplied slug, URL slug, generic fallback,
whitespace, empty label and nullable optionals. Initial, selected and post-Enter
captures retain complete model, DOM and portal strings. The tests also record the
three metadata-update tags and actual external opening. The initialized registry
and existing UI component are authoritative; there is no alternate renderer or
model-node substitute.

Compare independent original/hosted Source epochs byte for byte in Chromium,
Firefox and WebKit. Keep the original component preimage and captures outside the
repository. The compiled-dependency witness verifies the exact app-cache maps and
served Source modules for pristine Lexical and code-core in each execution.
The local Vite configuration uses the actual app plugins with file watching off.
Set BOOKING_SOURCE_CAPTURE, BOOKING_TEST_REPORT and BOOKING_TEST_OUTPUT to separate
output directories; use the sibling Playwright config with actual browser paths.

The native-ready leaf exports createNativeBookingLinkMentionContext(theme) and
createNativeBookingLinkMentionViews(context). Bind the real view and dispose the
context before runtime close. It uses published selection, the real Normal Enter
slot and generation-bound queued SessionEdit label updates. Its projector uses
the actual component registry and admits the proven nullable UI fields unchanged.
Native producer source alone does not establish a mounted native result: a new
matched shared native package containing group-b.booking-mention-label, literal
Source/native pairs and registry admission are still required. The 75ba files in
the isolated fixture are asset prerequisites, not proof of that new command.
