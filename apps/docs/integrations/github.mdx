Rox integrates with GitHub so your tasks stay in sync with the code that closes them. To connect, link your GitHub account in **Settings → Integrations**.

### Tasks that track your PRs

Create a branch for a task and Rox keeps the task's status up to date automatically: **In Progress** when you create the branch, **In Review** when you open the pull request, and **Completed** when it merges.

> With a task selected, press <kbd>shift</kbd>\+<kbd>cmd</kbd>\+<kbd>b</kbd> to copy a branch name for it.

The linked pull request appears directly on the task with its title, PR number, and diff size, so anyone looking at the task can jump straight to the code:

Pull requests are blocks like everything else in Rox: you can @mention them in channels and docs, and agents can read them for context. Find them in [Reviews](/product/reviews). See [Tasks](/product/tasks) for more on how tasks work.

## Reviews

Reviews is where GitHub pull requests live in Rox. Open one to read its description and discussion, and open **Changes** to see the diff. The side panel shows **Checks** and **Linked work**, including the task the pull request belongs to.

Connect your GitHub account first, as described above.

> To go to Reviews use shortcut <kbd>g</kbd> \+ <kbd>v</kbd>.

The sidebar groups them:

- **Pull requests**
- **Authored by me**
- **Assigned to me**
- **Involves me**
- **Review requests**

**Open**, **Closed**, and **All** switch which pull requests are shown. **List** shows them in a list. **Board** groups open pull requests into **Draft**, **In review**, **Checks failing**, **Conflicts**, **Ready to merge**, and **Merged**.

**Filter** narrows by status, priority, what a pull request is linked to, where it was started, repository, author, assignee, label, and review. **Sort** orders by priority, recently updated, or newest.
