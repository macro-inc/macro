A database tracks records that share a shape, such as parts, vendors, applicants, or a pipeline. Each row is one record. Each column is a field on that record.

Choose **Database** from the **Create** menu, or choose **New → Database** in [Drive](/product/drive).

## Types

A column holds one kind of value.

- **Text**
- **Number**
- **Select** and **Multi-select**, dropdowns with a color on each option
- **Date**
- **Time range**
- **Checkbox**
- **URL**
- **People**, **Documents**, and **Tasks**, a mention of that Block
- **Formula**, calculated from other columns
- **Related table**, a link to records in another table in this database

## Editing a database

Click a cell to edit it. Changes save as you work. Type in the empty row under the records to add a record. Click a row number, or choose **Open record**, to edit that record.

**Add column** adds a field. **Change type** on a column header sets what that field holds. **+ → New table** adds another table. **New view** saves the records as a table, a board, or a timeline.

## Collaborating

Other people in the database show up by name on the cells they have selected, and their edits appear as they save. If two people change the same cell, the later save stands. **Share** adds people or channels. On a team, **Team access** sets view, comment, or edit for the whole team. A saved view is the same for everyone who can open the database.

## Mentions

Type `@` in a cell to mention a Block. A column can hold a person, document, task, channel, email, project, company, or contact.

## AI editing

**AI** in the header opens a conversation with this database attached. The agent can answer questions about the records, or edit the records, columns, and tables. A [routine](/product/routines) can update them.
