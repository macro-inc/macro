Reviews is where GitHub pull requests live in Macro. Open one to read its description and discussion, and open **Changes** to see the diff. The side panel shows **Checks** and **Linked work**, including the task the pull request belongs to.

[Link your GitHub account](/integrations/github) before any of that shows up. A linked task moves to **In Progress**, **In Review**, and **Completed** as you branch, open the pull request, and merge.

> To go to Reviews use shortcut <kbd>g</kbd> \+ <kbd>v</kbd>.

The sidebar groups them:

- **Pull requests**
- **Authored by me**
- **Assigned to me**
- **Involves me**
- **Review requests**

**Open**, **Closed**, and **All** switch which pull requests are shown. **List** shows them in a list. **Board** groups open pull requests into **Draft**, **In review**, **Checks failing**, **Conflicts**, **Ready to merge**, and **Merged**.

**Filter** narrows by status, priority, what a pull request is linked to, where it was started, repository, author, assignee, label, and review. **Sort** orders by priority, recently updated, or newest.
