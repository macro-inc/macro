Every night, Macro refreshes this memory from the day's activity. It is a background profile of you: your role, what you are working on, and how you like to work. That profile is given to the agent at the start of a conversation.

Memory is the background, and it is the smaller part of how an agent knows your workspace. That background is why the agent already knows how you work at the start of a conversation, and why a search can go straight to the question. Search and tool calls are how it finds a current fact. The agent searches email, messages, tasks, docs, and call transcripts, then reads the thing it found. That result is live. The nightly summary is already a day old, and it leaves out anything you would look up on the spot. See [Search](/product/search).

### Personal vs. team memory

Every Macro user has a personal memory built from their own work. If you're on a team, there's also a shared team-level memory:

- **Tasks** are added to team memory by default, so everyone can see what others are working on.
- **Calls** started from a channel are recorded, transcribed, and shared with the team by default. Uncheck **Share with team** to keep one off the team. Standalone calls stay with the people on the call. See [Calls](/product/calls).
- **Emails** are auto-shared with the team where it makes sense, for example in the CRM module.

On a team, that background includes work the team has shared. When you ask about something specific, the agent still searches and reads the Blocks themselves.
