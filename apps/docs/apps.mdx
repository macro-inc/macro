## Web

Rox runs in any modern browser at [macro.com](https://macro.com), with no install required. Desktop is the full Rox experience: the keyboard-driven workflow, and a built-in window manager that lets you multi-task in splits inside a single tab, so Rox can replace a pile of browser tabs.

## Mobile

Rox has apps for iPhone and Android. They connect to the same workspace: notifications, email, chat, tasks, Drive, and agents on your phone. You can also find them in **Settings → Mobile App** in the web app. On a computer it shows a QR code for each store; in a phone browser it links straight to them.

### Desktop-only features

A few things stay desktop-only by design:

- **Splits**: the side-by-side window manager needs screen width; on mobile you work one Block at a time.
- **Keyboard shortcuts**: the <kbd>c</kbd> launcher and <kbd>j</kbd>/<kbd>k</kbd> navigation are desktop features.
- **Some settings**: managing email inboxes and agent connections is done from desktop.
