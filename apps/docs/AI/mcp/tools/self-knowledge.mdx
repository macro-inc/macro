# SelfKnowledge

Learn what Rox is and how it works. Call this whenever the user asks an open-ended question about Rox itself — what it is, what it's for, what it can do, or how to do something in Rox — instead of answering from memory (your training data may be stale). Takes no arguments. Returns an overview of Rox and a map of links into the official docs at docs.macro.com; every docs page is readable as Markdown (append `.md` to its URL), so follow up with WebFetch on the relevant page for details and cite it.
