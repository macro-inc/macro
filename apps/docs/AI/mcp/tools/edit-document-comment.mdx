# EditDocumentComment

Replace the text of a comment or reply on a document. Only a comment's author can edit it, so this edits comments the user wrote and comments this assistant wrote for them. Comment ids come from the comments ReadContent returns. Use only when the user asks to edit a comment.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `documentId` | string | Yes | The id of the document the comment is on. |
| `commentId` | string | Yes | The id of the comment or reply to edit, from ReadContent. For the first comment of a thread this is the thread id. |
| `content` | string | Yes | The full replacement text of the comment, in markdown. |
