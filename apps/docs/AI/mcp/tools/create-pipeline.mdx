# CreatePipeline

Create a CRM pipeline: a board of deals that move through stages, such as a sales, renewals, fundraising, hiring or partnership pipeline. Each entry tracks either a company or a contact. Every pipeline starts with the tracked record, Stage, Owner and Revenue fields; Stage starts with the team's default stages unless `stages` gives others. Only when the user asked for a new pipeline: check ListPipelines first so you do not create a duplicate. Returns the pipeline with its id and fields.

## Parameters

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | The pipeline's name, e.g. "Q4 Renewals". |
| `tracks` | `"company"` \| `"contact"` | Yes | What a pipeline's entries track. Documented on the fields that use it: a doc comment on a variant would turn the schema into `oneOf`. |
| `sharedWithTeam` | boolean | No | Let the user's team see and edit it. Defaults to false: only the user can see it. |
| `stages` | string[] | No | The stages, first to last, e.g. ["Sourced", "Screen", "Interview", "Offer", "Hired"]. Leave empty for the team's default stages. |
| `fields` | ToolNewField[] | No | Fields to add after Company/Contact, Stage, Owner and Revenue. |
