Rox's MCP endpoint is:

```text
https://mcp-server.macro.com/mcp
```

The server is remote; no local process is required. Authentication happens through Rox's OAuth flow when the client connects. Sign in with Google, a code sent to your email, or a password.
MCP access is available on every Rox plan, including Free.

## Claude Code

```bash
claude mcp add --transport http macro https://mcp-server.macro.com/mcp
```

Start Claude Code, use the `macro` MCP server, and complete the browser sign-in flow when prompted.

## Codex CLI

```bash
codex mcp add macro --url https://mcp-server.macro.com/mcp
```

Start Codex CLI, invoke the `macro` MCP server, and complete the OAuth login flow in the browser.

## Connect from a remote machine

If your client runs on another machine, such as over SSH or in a container, a browser on your computer can't reach the client when sign-in finishes. Sign in like this instead:

1. Start the login on the remote machine. For Claude Code, run `claude mcp login macro --no-browser`. For Codex CLI, run `codex mcp login macro`.
2. Open the printed link in a browser on your computer.
3. Select **The app I'm connecting runs on another machine**, then choose how to sign in.
4. After you sign in, Rox shows a link and a `curl` command. If your client asks for a redirect URL, as Claude Code does, paste the link. Otherwise, run the `curl` command on the remote machine while the client is waiting, as with Codex CLI.

## IDE / JSON Configuration

For editors that accept JSON MCP server config, add this under `mcpServers`:

```json
{
  "macro": {
    "type": "http",
    "url": "https://mcp-server.macro.com/mcp"
  }
}
```

Trigger a connection from the editor and finish the browser login flow.
