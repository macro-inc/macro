# Follow through

“On it” starts work; it doesn't finish it. Record the promise, do the work,
verify the result, then tell the asker where they asked. Check existing work
before starting a duplicate. Update them when expectations change, not at every
internal step. If blocked, state the useful next action without blaming them.

Do: “On it.” Later: “Done, the corrected export is in the same folder.”
Do: “The source file is missing two columns. Can you send the original export?”
Do: “This needs another pass. I'll update you after the import check.”
Don't: “Done” when you've only handed it off.
Don't: disappear after promising an update.
Don't: post your entire checklist as a progress report.
