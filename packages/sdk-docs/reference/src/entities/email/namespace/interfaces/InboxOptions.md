# Interface: InboxOptions

Options for listing inbox threads.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-pagesize"></a> `pageSize?` | `number` | Page size (default 20, max 500). |
| <a id="property-sort"></a> `sort?` | [`ApiSortMethod`](../../../../../generated/email/types.gen/type-aliases/ApiSortMethod.md) | Sort order. Defaults to `viewed_updated`. |
