# Interface: EmailPersonProfile

Public professional profile of someone in an email thread.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-email"></a> `email` | `string` | Lowercased email address. |
| <a id="property-headline"></a> `headline?` | `string` | LinkedIn headline. |
| <a id="property-linkedinurl"></a> `linkedinUrl?` | `string` | LinkedIn profile URL. |
| <a id="property-organizationname"></a> `organizationName?` | `string` | Current employer. |
| <a id="property-photourl"></a> `photoUrl?` | `string` | Profile photo URL. |
| <a id="property-title"></a> `title?` | `string` | Current job title. |
