# Interface: UploadProfilePictureOptions

How to store an uploaded profile picture.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-contenttype"></a> `contentType` | `string` | `image/png`, `image/jpeg`, `image/webp` or `image/gif`. |
| <a id="property-filename"></a> `fileName` | `string` | File name, such as `avatar.png`. |
