# Interface: ReferralLink

The caller's referral code and the signup link that carries it.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-code"></a> `code` | `string` | The caller's referral code. |
| <a id="property-url"></a> `url` | `string` | The signup URL that credits the caller when someone joins through it. |
