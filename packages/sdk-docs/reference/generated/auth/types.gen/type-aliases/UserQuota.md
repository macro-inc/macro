# Type Alias: UserQuota

> **UserQuota** = \{ `ai_chat_messages`: `number`; `documents`: `number`; `max_ai_chat_messages`: `number`; `max_documents`: `number`; \}

The UserQuota represents the user's current quota

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-ai_chat_messages"></a> `ai_chat_messages` | `number` | The user's total number of AI chat messages the user has sent. |
| <a id="property-documents"></a> `documents` | `number` | The user's total number of documents they have created. |
| <a id="property-max_ai_chat_messages"></a> `max_ai_chat_messages` | `number` | The maximum number of AI chat messages they can send. |
| <a id="property-max_documents"></a> `max_documents` | `number` | The maximum number of documents they can create. |
