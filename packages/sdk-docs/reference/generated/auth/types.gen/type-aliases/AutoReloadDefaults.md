# Type Alias: AutoReloadDefaults

> **AutoReloadDefaults** = \{ `minimum_balance_cents`: `number`; `target_balance_cents`: `number`; \}

The automatic reload thresholds a payer starts from.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-minimum_balance_cents"></a> `minimum_balance_cents` | `number` | Balance below which a reload fires, cents. |
| <a id="property-target_balance_cents"></a> `target_balance_cents` | `number` | Balance a reload tops up to, cents. |
