# Type Alias: GithubPullRequestLabel

> **GithubPullRequestLabel** = \{ `color?`: `string` \| `null`; `name`: `string`; \}

A label on a GitHub pull request.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-color"></a> `color?` | `string` \| `null` | The label color as six hex digits without a leading `#`, when known. |
| <a id="property-name"></a> `name` | `string` | The label name, unique within its repository regardless of case. |
