# Type Alias: WebCitation

> **WebCitation** = \{ `description?`: `string` \| `null`; `favicon_url?`: `string` \| `null`; `image_url?`: `string` \| `null`; `title`: `string`; `url`: `string`; \}

A web citation associated with a chat message.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-description"></a> `description?` | `string` \| `null` | A description of the cited page. |
| <a id="property-favicon_url"></a> `favicon_url?` | `string` \| `null` | The URL of the page's favicon. |
| <a id="property-image_url"></a> `image_url?` | `string` \| `null` | The URL of the page's image. |
| <a id="property-title"></a> `title` | `string` | The title of the cited page. |
| <a id="property-url"></a> `url` | `string` | The URL of the citation. |
