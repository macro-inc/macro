# Type Alias: InputPropertyDefinition

> **InputPropertyDefinition** = \{ `name`: `string`; `options?`: `string`[]; \}

A task property and the display values available for extraction.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-name"></a> `name` | `string` | Property display name from the client's catalog. |
| <a id="property-options"></a> `options?` | `string`[] | Allowed display values; an empty list permits free-text suggestions. |
