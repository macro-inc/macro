# Type Alias: MonthlyWeekday

> **MonthlyWeekday** = \{ `ordinal`: `number`; `weekday`: [`WeekdayCode`](WeekdayCode.md); \}

Monthly ordinal weekday, such as the first Friday.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-ordinal"></a> `ordinal` | `number` | One through five, or minus one for last. |
| <a id="property-weekday"></a> `weekday` | [`WeekdayCode`](WeekdayCode.md) | Weekday selected by the ordinal. |
