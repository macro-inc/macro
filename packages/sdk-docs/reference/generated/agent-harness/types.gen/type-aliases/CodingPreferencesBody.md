# Type Alias: CodingPreferencesBody

> **CodingPreferencesBody** = \{ `createTasks`: `boolean`; `openPullRequests`: `boolean`; \}

Request or response body for the caller's coding preferences.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-createtasks"></a> `createTasks` | `boolean` | Whether new coding sessions research prior work and link a Macro task. |
| <a id="property-openpullrequests"></a> `openPullRequests` | `boolean` | Whether new coding sessions deliver their work as a pull request. |
