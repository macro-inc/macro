# Type Alias: AgentSetConfigOptionAction

> **AgentSetConfigOptionAction** = \{ `configId`: `string`; `value`: `string`; \}

Ask the agent to change one advertised select-style session setting.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-configid"></a> `configId` | `string` | Opaque ACP config id advertised by the agent. |
| <a id="property-value"></a> `value` | `string` | Opaque select value advertised for that config option. |
