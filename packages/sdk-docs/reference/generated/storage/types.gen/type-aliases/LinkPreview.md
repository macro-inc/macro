# Type Alias: LinkPreview

> **LinkPreview** = \{ `description?`: `string` \| `null`; `favicon_url?`: `string` \| `null`; `image_url?`: `string` \| `null`; `title`: `string`; `url`: `string`; \}

A preview of a web page a message links to: what its card shows.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-description"></a> `description?` | `string` \| `null` | The page description, if any. |
| <a id="property-favicon_url"></a> `favicon_url?` | `string` \| `null` | The page's favicon URL, if any. |
| <a id="property-image_url"></a> `image_url?` | `string` \| `null` | The page's preview image URL, if any. |
| <a id="property-title"></a> `title` | `string` | The page title. |
| <a id="property-url"></a> `url` | `string` | The linked URL, as the message text links it. |
