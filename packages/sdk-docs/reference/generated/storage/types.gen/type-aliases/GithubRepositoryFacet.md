# Type Alias: GithubRepositoryFacet

> **GithubRepositoryFacet** = \{ `count`: `number`; `repository`: `string`; `repositoryId`: `string`; \}

A repository among the visible GitHub pull requests.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-count"></a> `count` | `number` | Number of visible pull requests in the repository. |
| <a id="property-repository"></a> `repository` | `string` | The repository's most recently synced name, as `owner/repo`. |
| <a id="property-repositoryid"></a> `repositoryId` | `string` | The numeric GitHub repository id, which survives renames and transfers. |
