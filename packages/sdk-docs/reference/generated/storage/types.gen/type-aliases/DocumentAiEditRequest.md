# Type Alias: DocumentAiEditRequest

> **DocumentAiEditRequest** = \{ `fast?`: `boolean`; `instructions`: `string`; \}

What to change, in words.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-fast"></a> `fast?` | `boolean` | Run the single-model fast pipeline, for one small, contained edit. |
| <a id="property-instructions"></a> `instructions` | `string` | Natural-language instructions. Name the section or quote the text to change, describe the outcome, and say what must stay as it is. |
