# Type Alias: ApiDeadlineBoundaries

> **ApiDeadlineBoundaries** = \{ `day_eight`: `string`; `day_two`: `string`; `today`: `string`; `tomorrow`: `string`; \}

Frozen viewer-local day boundaries used to group task deadlines.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-day_eight"></a> `day_eight` | `string` | UTC start of the viewer's local day eight days ahead. |
| <a id="property-day_two"></a> `day_two` | `string` | UTC start of the viewer's local day two days ahead. |
| <a id="property-today"></a> `today` | `string` | UTC start of the viewer's current local day. |
| <a id="property-tomorrow"></a> `tomorrow` | `string` | UTC start of the viewer's next local day. |
