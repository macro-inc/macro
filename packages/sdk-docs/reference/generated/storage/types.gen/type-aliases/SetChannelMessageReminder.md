# Type Alias: SetChannelMessageReminder

> **SetChannelMessageReminder** = \{ `description`: `string`; `remindAt`: `string`; \}

Request to schedule or replace a message reminder.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-description"></a> `description` | `string` | Snippet shown in the notification. |
| <a id="property-remindat"></a> `remindAt` | `string` | When to notify the owner. Must be in the future. |
