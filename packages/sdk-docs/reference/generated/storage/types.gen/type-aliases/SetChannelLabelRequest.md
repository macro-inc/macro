# Type Alias: SetChannelLabelRequest

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-labelid"></a> `labelId?` | `string` \| `null` | The label to put the channel in, or `null` to remove it from its label. |
