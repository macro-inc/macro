# Type Alias: Answer

> **Answer** = \{ `question`: `string`; `value`: [`CellValue`](CellValue.md); \}

One question's answer: a value for its column, typed as the column's
cells are.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-question"></a> `question` | `string` | The question. |
| <a id="property-value"></a> `value` | [`CellValue`](CellValue.md) | The value; `clear` for no answer. |
