# Type Alias: Vec

> **Vec** = \{ `events`: `string`[]; `ids?`: `string`[] \| `null`; \}[]

## Type Declaration

| Name | Type | Description |
| ------ | ------ | ------ |
| `events` | `string`[] | Event names matched by this filter. |
| `ids?` | `string`[] \| `null` | Entity ids matched by this filter. When absent, the filter matches all entity ids. |
