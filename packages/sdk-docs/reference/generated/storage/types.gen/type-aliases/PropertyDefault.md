# Type Alias: PropertyDefault

> **PropertyDefault** = \{ `propertyId`: `string`; `value`: [`SetPropertyValue`](SetPropertyValue.md); \}

A reusable default using the task creation property's existing value contract.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-propertyid"></a> `propertyId` | `string` | Definition that receives the default. |
| <a id="property-value"></a> `value` | [`SetPropertyValue`](SetPropertyValue.md) | Default value; absence from the configuration leaves the field blank. |
