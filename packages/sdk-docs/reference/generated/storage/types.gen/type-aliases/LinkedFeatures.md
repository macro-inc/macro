# Type Alias: LinkedFeatures

> **LinkedFeatures** = \{ `adoption`: `boolean`; `pairing`: `boolean`; `sending`: `boolean`; \}

Independently controlled backend rollout switches. None grants access.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-adoption"></a> `adoption` | `boolean` | Allow explicit existing-group adoption and access grants. |
| <a id="property-pairing"></a> `pairing` | `boolean` | Allow new owner-bound pairing transactions. |
| <a id="property-sending"></a> `sending` | `boolean` | Allow new deliberate sends. |
