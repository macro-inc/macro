# Type Alias: LinkedAdoptGroup

> **LinkedAdoptGroup** = \{ `group_jid`: `string`; \}

Explicit adoption request; the account is selected server-side. The
group's name always follows WhatsApp.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-group_jid"></a> `group_jid` | `string` | A group the requester's account has joined, or a direct chat from their chat list (the other person's JID, as the list names it). |
