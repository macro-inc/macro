# Type Alias: NoteDocument

> **NoteDocument** = \{ `documentId`: `string`; `name`: `string`; \}

A document available in the note picker.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-documentid"></a> `documentId` | `string` | Markdown document identity. |
| <a id="property-name"></a> `name` | `string` | Current document name, never a copied title. |
