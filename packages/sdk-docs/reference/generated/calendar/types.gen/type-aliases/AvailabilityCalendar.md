# Type Alias: AvailabilityCalendar

> **AvailabilityCalendar** = \{ `calendarId`: `string`; `contributesToAvailability`: `boolean`; `isPrimary`: `boolean`; `name`: `string`; \}

Per-user inclusion of a source calendar in personal availability.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-calendarid"></a> `calendarId` | `string` | Visible source calendar. |
| <a id="property-contributestoavailability"></a> `contributesToAvailability` | `boolean` | Whether its events normally block the user's time. |
| <a id="property-isprimary"></a> `isPrimary` | `boolean` | Whether this is the connected account's primary calendar. |
| <a id="property-name"></a> `name` | `string` | Source name. |
