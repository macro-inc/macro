# Pure public utilities

Forward only graph-free view producers with exact public signatures. Use actual
core classes for any future editor/node relationship; do not expose minimal view
contracts as public core types or alias Original runtime functions. Preserve
inline/block DOM predicate private brands through canonical DOM-only type targets;
keep target extraction internal, with bidirectional ordinary type controls.

Keep class-name normalization and DOM predicates bound to the existing view
implementations. DOM private marker fields are pinned data-only fields. Marking
events uses the original direct property assignment through an optional-property
local type, without casts or changed setter/exception behavior.

## Checks

Keep the jsdom directive on DOM tests so the default package runner also uses a
real DOM. Run pure.config.mts tests against independent Original controls, strict package
types/hooks, ordinary declaration emission, cold import and scoped just check.
These helpers do not bind an editor, clone authority or the native oracle.

Use tree.ts for pinned actual-node traversal and raw detach source algorithms.
Raw detach currently rejects missing __first write authority; keep that native
gate open without substituting Node.remove or a fabricated writable stage.
