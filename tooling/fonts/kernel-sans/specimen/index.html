Four details on a familiar skeleton

The proportions follow Inter and SF Pro: a 540-unit x-height on a 720 cap height, flat horizontal terminals and nearly even strokes. Everything that makes it feel engineered comes from four rules.

Weights

Six weights, one variable axis

Every outline is computed from the stem width, so the static weights and the variable font come from the same drawing.

    Use it on the web

    Files live in tooling/fonts/kernel-sans/fonts/: the variable font in variable/ and each static weight as otf/, ttf/ and woff2/.

    @font-face {
  font-family: "Kernel Sans";
  src: url("KernelSans[wght].woff2") format("woff2");
  font-weight: 300 800;
  font-display: swap;
}

body {
  font-family: "Kernel Sans", system-ui, sans-serif;
}
