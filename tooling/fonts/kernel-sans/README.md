# Kernel Sans

A neo-grotesque sans close to Inter and SF Pro, with a technical edge:

- **Squircle curves.** Round letters are superellipses, squarer than SF Pro.
- **45° chamfers** on free stem tops and curve terminals.
- **Ink traps** at acute joins, which grow with weight.
- **Square dots** with two opposing chamfers on i, j and punctuation.

Open `specimen/index.html` in a browser for a live specimen: weight slider, type
tester, the full glyph set and outline views of each detail.

## Files

| Path | Contents |
| --- | --- |
| `fonts/variable/KernelSans[wght].woff2` | Variable font for the web, weight 300–800 |
| `fonts/variable/KernelSans[wght].ttf` | Variable font for desktop apps |
| `fonts/woff2/`, `fonts/otf/`, `fonts/ttf/` | Static Light, Regular, Medium, SemiBold, Bold, ExtraBold |

## Use on the web

```css
@font-face {
  font-family: "Kernel Sans";
  src: url("KernelSans[wght].woff2") format("woff2");
  font-weight: 300 800;
  font-display: swap;
}

body {
  font-family: "Kernel Sans", system-ui, sans-serif;
}

/* Tables and counters */
.numeric {
  font-variant-numeric: tabular-nums;
}
```

## OpenType features

| Feature | Effect |
| --- | --- |
| `kern` | Class kerning, measured from the outlines at each weight |
| `liga` | fi and fl ligatures |
| `tnum` | Tabular figures; the defaults are proportional |
| `zero` | Slashed zero |
| `ss01` | Single-storey a |
| `case` | Brackets, dashes, guillemets, math and accents raised for capitals |

## Character set

Basic Latin, Latin-1 Supplement, the rest of Windows-1252 (Œ œ Š š Ž ž Ÿ ƒ, curly
quotes, dashes, daggers, ‰, €, ™), dotless i and j, fractions and superiors,
common math (− × ÷ ± ≠ ≈ ≤ ≥ ∞) and arrows (← ↑ → ↓ ↔ ↗ ↘).

## Building

The fonts are generated by Python; see [AGENTS.md](AGENTS.md) for the layout and
[DESIGN.md](DESIGN.md) for the rules every glyph follows.

```sh
pip install fonttools skia-pathops brotli freetype-py
python3 build.py                        # fonts/ and specimen/
python3 -m unittest discover tests      # coverage, outlines, variable compatibility
```

Proportions were checked against Inter (SIL Open Font License 1.1) while
drawing; no outlines from Inter or SF Pro are used.
