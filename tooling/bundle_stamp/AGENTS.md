# bundle_stamp

## What it is

Native app OTA updates. The `bundle-stamp` binary, the only producer of
`dist/bundle-manifest.json`: every web bundle build (web deploys, iOS, Android,
desktop Nix, local `just build-*`) stamps its identity from the source commit
here. Types and encoding live in `crates/bundle_identity`.

## Start here

- `src/main.rs`: `stamp` (manifest + `index.html` placeholder), `verify`
  (deploy check and rollback guard), `number` (a commit's `BundleBuild`, for
  update policy ranges).

## Callers

- `apps/web/package.json` `postbuild:bundle-manifest` (stamps `HEAD`).
- `nix/tauri-desktop.nix` (passes `--commit/--commit-time`, `--no-built-at`).
- `.github/workflows/build_web_app.yml` (`verify`, generated by `cargo x workflows`).

## Checks

- `cargo test -p bundle_stamp`

## Gotchas

- There is deliberately no flag that sets the number; add a commit source, not a number.
- Excluded from hakari like `xtask`: its clap features must not reach service builds.
