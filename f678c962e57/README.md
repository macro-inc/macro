# IMAP / SMTP lab proof

Real app and real local stack, test content only. This recording uses the manual **Other email (IMAP / SMTP)** route.

Stand-ins: Dovecot supplies IMAP and SMTP; Mailpit captures accepted SMTP; a synthetic SMTP gateway forces RCPT 550; LocalStack emulates KMS; sign-in identities and feature flags are synthetic local services. Captured MIME is deliberately appended into the controlled recipient INBOX to demonstrate threading. **SMTP acceptance is not recipient delivery.** No real-provider inbox or credential is recorded. SMTP submission counts are scoped per RFC message, not the total of all separate test messages across both accounts.
