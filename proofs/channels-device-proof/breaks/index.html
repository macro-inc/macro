Channels on the device: the deliberate breaks

Back to the result page

To show that each test can fail, the product was broken on purpose where the behaviour lives, the app rebuilt, and the tests run against it. These are the 74 patches, what each run did, and which break each of 168 tests failed for. They were in pull request #10868 under ledger/breaks/ and ledger/proofs.tsv until 17 November 2026, when they were taken out of the committed suite; this is the copy that was kept.

The patches apply to the branch as it was at a0b9c92622 (approach B at ce183ced7f). Eight were built and run on that head; the others were last run on earlier heads and only checked to still apply. None was run again after the merge that removed them. A row that says a marked check failed is a test whose check is recorded as failing in some runs: under the break it failed every time.

What each run did

  • results15.tsv: the breaks built on ce183ced7f (patch, test, outcome, error).
  • results.tsv: every break on earlier heads.
  • results-device-fresh.tsv, results-stale-engine.tsv, results-before-63e04.tsv: the device breaks on three earlier builds.
  • proofs.tsv: the table below as a file.
